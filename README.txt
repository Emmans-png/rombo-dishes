ROMBO DISHES — SUPABASE BACKEND STARTER

Read SETUP-WINDOWS.md for the complete Windows setup.

Files:
- index.html: customer-facing site with cart and checkout
- app.js: menu loading and checkout client
- supabase-config.js: public project URL and anon/publishable key placeholders
- admin.html / admin.js: admin login, menu management, order management
- supabase/schema.sql: database tables and row-level security policies
- supabase/functions/place-order/index.ts: server-side order validation and creation
- supabase/config.toml: Edge Function JWT setting

Important: this package is not connected to any Supabase account. Online M-Pesa is disabled pending secure Daraja integration and testing.
